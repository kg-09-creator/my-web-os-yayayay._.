# my-web-os-yayayay._.

WaveOS! It's an ocean themed OS with an ocean background and ocean-themed apps :D

Basically it's an ocean themed Operating System featuring draggable windows - it's got a notes app with a few ocean-themed facts and a welcome screen. 

<img width="1917" height="867" alt="Screenshot 2026-10-27 215306" src="https://github.com/user-attachments/assets/fb1643b5-eb08-4626-bfa6-198187cca533" />

Demo link: https://kg-09-creator.github.io/my-web-os-yayayay._./


How to use: Open the link. click and drag the windows and hit "Minimize all windows" to close all windows, and click the blue circles to close each individual window. Then click WaveOS in the upper left corner to bring back the welcome window.

- multiple draggable windows
-   a notes app
-   a welcome screen
- clickable buttons
- clock with local time updating each second
- ocean-themed UI
